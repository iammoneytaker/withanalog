# 실행 기록

- 완료: 독거미 6개 모델 출처 데이터, 목록/상세/비교, 기술 SEO·사이트맵·구조화 데이터, 가이드 6개, 입력/KPS/재입력 도구.
- 완료: 단일 공통 헤더, 내부 도구 스타일 통일, 실제 대표 사진(사용자 요청·권리 협의 사용자 진행), 확인일 표기.
- 완료: 기존 Supabase에 제휴 링크 저장 테이블/RLS, 지정 관리자 계정 생성·권한 부여, 관리자 로그인·비공개 저장·새로고침 확인.
- 보호: 기존 성능 테스트 파일·측정 컴포넌트·공유 사운드 로직 변경 없음. 최신 사용자 요청으로 공통 Header와 도구 외부 스타일 변경은 허용됨.
- 검증: 빌드·타입검사·lint 통과. 기존 tester 실제 입력 2회 집계. 비공개 링크의 익명 조회 차단. URL 형식 검증은 DB 쓰기 없이 수행.
- 검증 진행: 최종 독립 화면 검토.
- 미완료: 실제 모델 일치 쿠팡 제휴 URL 등록·공개, 운영 배포, GSC/Bing 사이트맵 제출.
- 별도 후속: 사용자 실측 제보 온라인 접수/검토는 아직 연결되지 않았으며 현재는 로컬 파일 저장 기능.
